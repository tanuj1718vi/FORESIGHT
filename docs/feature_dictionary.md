# Project FORESIGHT — Feature Dictionary & Engineering Contracts

This document details the engineered feature space generated by `FeatureEngineeringPipeline` for machine learning demand forecasting.

**Total Predictive Features:** `48`  
**Target Column:** `quantity`  
**Warmup Horizon:** `56 days`  

---

## 1. Feature Groups & Columns

### 1.1 Temporal & Calendar Features
| Feature Name | Type | Mathematical Formulation / Description |
| :--- | :--- | :--- |
| `day_of_week` | `int` | Integer day of week ($0 = \text{Monday}, 6 = \text{Sunday}$) |
| `day_of_month` | `int` | Day of calendar month ($1 - 31$) |
| `week_of_year` | `int` | ISO calendar week number ($1 - 53$) |
| `month` | `int` | Month number ($1 - 12$) |
| `quarter` | `int` | Fiscal quarter ($1 - 4$) |
| `year` | `int` | Observation calendar year |
| `is_weekend` | `int` | Binary flag ($1$ for Saturday/Sunday, $0$ otherwise) |
| `sin_day_of_week` | `float` | $\sin(2\pi \times \text{day\_of\_week} / 7)$ cyclical encoding |
| `cos_day_of_week` | `float` | $\cos(2\pi \times \text{day\_of\_week} / 7)$ cyclical encoding |
| `sin_month` | `float` | $\sin(2\pi \times (\text{month}-1) / 12)$ annual cycle encoding |
| `cos_month` | `float` | $\cos(2\pi \times (\text{month}-1) / 12)$ annual cycle encoding |

### 1.3 Causal Rolling Window Features (Computed on $\text{shift}(1)$)

| `rolling_mean_28` | `float` | Mean daily sales over $[t-28, t-1]$ |
| `rolling_std_28` | `float` | Standard deviation of daily sales over $[t-28, t-1]$ |
| `rolling_min_28` | `float` | Minimum daily sales over $[t-28, t-1]$ |

### 1.4 Velocity & Trend Features
| Feature Name | Type | Description |
| :--- | :--- | :--- |
| `demand_growth_7_28` | `float` | $(\text{rolling\_mean\_7} - \text{rolling\_mean\_28}) / \text{rolling\_mean\_28}$ |

## 2. Zero-Leakage Guarantee

All lag and rolling operators are strictly backward-looking. For any prediction at time $t$:
$$\mathbf{X}_t = f\left(y_{t-1}, y_{t-2}, \dots, y_{t-56}, \text{calendar}(t), \text{commercial}(t)\right)$$
Under no circumstances is $y_t$ or any $y_{t+k}$ accessible during feature calculation.
